# De Zero a Dev — Exercises

This repository contains my exercise solutions and project work from *De Zero a Dev*, an e-book by Rafael Gottardi that covers a full path from computing fundamentals to backend development, including Linux, Git, Python, Docker, C, databases, C#, software architecture, and APIs.

## About this repository

Each module in the book includes a set of exercises (roughly five per module), along with larger standalone projects at the end of several chapters. This repository holds my solutions to those exercises and projects as I work through the material.

I initially planned to keep my answers alongside the book itself, but decided a separate repository made more sense — it's easier to track progress over time and gives me something concrete to show for the work.

## Structure

Solutions are organized by chapter and module, following the book's own numbering. Chapter-level projects are kept in their own folders, separate from the individual module exercises.

## Topics covered

Linux and the command line, Git and version control, Python, Docker and containers, C and data structures, relational databases, C# and object-oriented programming, software architecture, and API design.

## Note

This repository contains only my own solutions and notes. It does not include or reproduce any content from the book itself.  
If you want the original material, please contact the creator, not me.
